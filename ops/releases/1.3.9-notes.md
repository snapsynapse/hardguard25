# HardGuard25 1.3.9 release notes

This patch makes identifier parsing consistent across JavaScript, Python and Go, preserves canonical identity when the browser generator formats codes, and closes gaps in the release and deployment checks.

## Fixed

- Fold only ASCII a-z during parsing and checksum calculation. Non-ASCII case expansions such as U+FB00 are rejected consistently; permitted Unicode separators remain supported.
- Limit individual JavaScript entropy requests to the Web Crypto quota while retaining rejection sampling, refills and entropy-failure propagation.
- Restrict generator separators so displayed and copied codes normalize to the original identifier and retain their checksum.
- Replace incorrect specification generation vectors and source checksum examples with executable, checked examples.

## Release and documentation maintenance

- Require canonical and browser validation before Pages deployment of the same commit.
- Pin all workflow actions to reviewed commit hashes.
- Stop npm/PyPI publication when artifacts already exist, and reject a pre-existing Go tag at a different commit. Partial releases require explicit artifact-identity reconciliation.
- Distinguish lookup identifiers from bearer/authentication secrets across human and agent guidance.
- Refresh guide mirrors, hashes, skill metadata, conformance evidence and package citation metadata.

The fixed alphabet, checksum algorithm and canonical ASCII identifiers are unchanged. This release does not add a hosted API or establish comparative OCR/transcription performance.

## Validation

The fixes passed 469 cross-runtime parity cases, 77 JavaScript tests, 47 Python tests, Go tests, clean package consumers, ten browser tests, workflow linting and independent adversarial review. The 1.3.9 candidate also passed its local verifier and browser suite. Exact-head CI and independent publication evidence are recorded in [the release state](https://github.com/snapsynapse/hardguard25/blob/main/ops/releases/1.3.9.json).

The local Python tooling refresh resolves the review's eleven advisory/package pairs. Those environment packages are not HardGuard25 runtime dependencies and are not distributed in these packages.
