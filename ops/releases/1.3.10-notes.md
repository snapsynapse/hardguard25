# HardGuard25 1.3.10 release notes

This maintenance release keeps the fixed alphabet and normalization rules while hardening long-input checksum correctness, the browser generator, search checking, and release publication.

## Fixed

- Preserve exact Mod-25 checksums for long payloads across JavaScript, Python and Go, including 32-bit Go. Exported JavaScript and Go lookup snapshots can no longer mutate validation behavior.
- Decode sitemap entities once, reject malformed sitemap structure, confine requests and redirects to the configured origin, and distinguish incomplete collection from observed site defects.
- Recover cleanly from generator entropy and clipboard failures. Displayed, copied and accessible identifiers stay aligned after setting changes. Correct the GitHub star link accessible name.

## Release integrity

- Build and verify the exact npm, wheel and sdist artifacts before publication. Publisher jobs consume those artifacts with a source-bound digest and stop unless npm version absence is authoritative.
- Use hash-pinned patched Python build tools. Source builds require Python 3.10 or newer; installed wheels continue to support Python 3.9 or newer. Runtime packages remain dependency-free.
- Add deterministic specification, generator, search, artifact and workflow checks, plus executed Linux/386 tests.

The check digit remains a human-entry aid, not authentication. This release makes no comparative OCR or transcription performance claim.
